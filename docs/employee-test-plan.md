# Employee Test Plan

## Goal

Test whether the prototype actually helps PENCIL HR and managers organize workplace concerns and prepare better communication.

## Testers

Target a small pilot:
- 1 HR tester
- 2–4 managers
- Optional additional staff for usability feedback

## Scenarios

Use 3–5 anonymized or fictionalized scenarios inspired by interview patterns.

Do not use real names, client names, medical diagnoses, or confidential HR details.

## HR test questions

After using the Issue Organizer:
- Does the output correctly separate facts from interpretation? (1–5)
- Does it organize the situation objectively? (1–5)
- Did it add any incorrect assumptions? (Yes/No + comment)
- Are the clarification questions useful? (1–5)
- Would this reduce the time needed to understand or prepare a case? (1–5)
- Would you actually use this in your workflow? (Yes/Maybe/No)
- What should be changed?

## Manager test questions

After using Manager Communication Support:
- Is the suggested approach practical? (1–5)
- Does it reflect the employee's stated preferences without stereotyping? (1–5)
- Did it suggest anything inappropriate or unrealistic? (Yes/No + comment)
- Would this make it easier to prepare for the conversation? (1–5)
- Would you use it? (Yes/Maybe/No)
- What should be changed?

## Evidence for final presentation

Record only aggregate/anonymized results, for example:
- Number of PENCIL employees who tested the prototype
- Average usefulness score
- Average objectivity score
- Percentage who would use or maybe use it
- Most common requested improvement
- One or two anonymized quotes with permission

Never invent results. Only present actual test data.
